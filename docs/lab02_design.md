# Lab02 — Проєктування класу Book

## Мета
Визначити, які операції має підтримувати клас `Book` і який мінімальний
набір полів потрібен для їх підтримки. Усі похідні величини викреслено —
вони обчислюються методами, а не зберігаються.

## Операції, яких програма чекає від Book

### Ідентифікація книги
- `getTitle()` — повернути назву книги
- `getAuthor()` — повернути автора
- `getIsbn()` — повернути ISBN
- `getYear()` — повернути рік видання

### Облік примірників
- `getTotalCopies()` — повернути загальну кількість примірників
- `getAvailableCopies()` — повернути кількість доступних примірників
- `lentOut()` — **обчислити** кількість виданих примірників
- `lend()` — видати один примірник (зменшити available)
- `returnCopy()` — повернути один примірник (збільшити available)
- `isAvailable()` — **обчислити**, чи є вільні примірники

### Аналіз / класифікація
- `isOlderThan(int year)` — **обчислити**, чи книга старша за вказаний рік
- `getAge(int currentYear)` — **обчислити** вік книги

### Службові
- `isValidIsbn()` — **обчислити**, чи коректний ISBN (довжина, формат)
- конструктор з усіма значущими полями

## Поля, потрібні для підтримки операцій

### Обов'язкові (зберігаються)
- `title_` — `std::string` — назва книги
- `author_` — `std::string` — автор
- `isbn_` — `std::string` — ISBN (13 символів)
- `year_` — `int` — рік видання
- `totalCopies_` — `int` — загальна кількість примірників
- `available_` — `int` — кількість доступних примірників

### Похідні (НЕ зберігаються, обчислюються методами)
- ~~`lentOut_`~~ — обчислюється як `totalCopies_ - available_`
- ~~`isAvailable_`~~ — обчислюється як `available_ > 0`
- ~~`age_`~~ — обчислюється як `currentYear - year_`
- ~~`isValidIsbn_`~~ — обчислюється з `isbn_`

## Обґрунтування

Кожне поле з групи «обов'язкові» **не можна** обчислити з інших:
- `title_`, `author_`, `isbn_`, `year_` — це вхідні дані про книгу;
- `totalCopies_` — фізична кількість у бібліотеці;
- `available_` — поточний стан (змінюється при видачі/поверненні).

Кожна величина з групи «похідні» **виводиться** з обов'язкових:
- `lentOut() = totalCopies_ - available_`;
- `isAvailable() = available_ > 0`;
- `getAge(currentYear) = currentYear - year_`.

Зберігати їх окремо означало б дублювання даних і ризик розсинхронізації.

## Інваріанти класу
- `0 <= available_ <= totalCopies_`
- `year_ > 0` і `year_ <= поточний рік`
- `isbn_.length() == 13` (або 10 для старого формату)
- `totalCopies_ >= 1`
